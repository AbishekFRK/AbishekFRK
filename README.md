# Hi, I'm Abishek 👋

**GIS and geospatial software engineer.** I build web GIS, drone and mission-planning tools, satellite-imagery analysis and the full-stack products around them.

## What I work with

**Geospatial:** OpenLayers · CesiumJS · MapLibre · Leaflet · deck.gl · PostGIS · GDAL / rasterio · OGC services (WMS, WFS, WMTS) · satellite and drone imagery · terrain and elevation analysis
**Frontend:** TypeScript · React · Next.js · Angular · Vite
**Backend:** Python (FastAPI) · Java (Spring Boot) · Node.js (Express) · Rust · PostgreSQL
**Platform:** Docker · Nx monorepos · offline-first and air-gapped deployments
